# Promote make.fun's make-your-own-bounty post on X

Entry for the make.fun bounty **post-x-promote-make-your-own-bounty-01** — $250 shared by the top 50 posts (1st $50, 2nd $30, 3rd $15, 4th–10th $5, 11th–50th $3), no entry fee. Deadline 27 Nov 2026 01:35 WIB.

The entry is one post on X that quotes (or links to) make.fun's make-your-own-bounty post, with a photo of its own attached, and the text carrying make.fun / @makefunai plus our play code `makefun-snail-wave-garland`. Places go by the post's replies + reposts + quotes as read at the deadline; views and likes count for nothing.

How it works: `main.ts` (Node 22, standard library only) reads `POST.json`, checks it names an X post address (`https://x.com/<handle>/status/<id>`), and copies it byte for byte to the output directory. `POST.json` holds the address of the post; it is filled in once the post is live.

## The post

One post on X, made between the opening (23 Nov 2026 18:35 UTC) and the deadline (26 Nov 2026 18:35 UTC), from a public account. It quotes make.fun's post (https://x.com/makefunai/status/2124915864336236646) or links to it, carries a photo of its own, and its text carries make.fun / @makefunai and the play code `makefun-snail-wave-garland`. The post stays up and public until the results are out. No bought, botted or self-made engagement: the admins disqualify it.

## Scoring

Score = the post's replies + reposts + quotes as read at the deadline, highest first. Views and likes move nothing. An exact tie goes to the earlier receipt. The program writes nothing about the post: the house reads the post itself.
